# Тестирование временной связки ESP32-S3 + STM32F401RCT6 — только для модернизации Ё-радио

## Что у тебя есть для теста (по твоему уточнению)
- **На слух** — основной критерий: скорость норм, нет дропов, нет щелчков при Fs смене, seek без клика.
- **Web UI родной Ё-радио** — через WiFi (yoRadio web интерфейс).
- **UART ESP32-S3** — Serial 115200 (позже 460800/921600 для OMNIA). CLI команды `mode`, `prev/next`, `vol`, `info`, `list` + новые `seek`, `shuffle`, `repeat`, `usb_*`, `status`, `ping` + исходящие `##PROGRESS#`, `##META#`, `##SD/USB.STATUS#`.
- **UART STM32F401RCT6** — PA2/PA3 115200, команды `s`, `s1000`, `s0` автостатус, логи MUTE/RATE retune, `gain/fade/mute`. Через него ты проверял мьют и прочее.

## Нужен ли UART STM32 в модернизации?

**Для временной связки — полезен как отладочный, но не обязателен для финального функционала:**

- **Сейчас (V7G → v8.2):** оставь STM32 UART как **опциональный debug**. Он помогает быстро видеть что `RATE_PIN PA9` переключился, `MUTE PA8` HIGH/LOW, retune без overrun. Без него ты тоже поймешь на слух (если RATE неправильный — скорость ускорена + дропы), но с UART быстрее.
- **После модернизации Ё-радио (когда модуль готов к интеграции в OMNIA):** STM32F401 полностью убирается, его заменяет **AT32 v·core** (тоже I2S MASTER в RADIO домене). AT32 будет следить за `GPIO4 RATE` от ESP32-S3 точно так же как STM32 сейчас, и делать тот же retune. Его диагностика — свой отдельный UART (на стороне v·core), а не PA2/PA3.
- **Финальный Ё-радио модуль (standalone):** для работы вне OMNIA STM32 UART не нужен. ESP32-S3 сам знает Fs, выставляет RATE_PIN, держит MUTE. Можешь слушать PCM5102A напрямую от ESP32-S3 если переключишь ESP в MASTER (но в OMNIA нам нужен SLAVE, поэтому сейчас MASTER = STM32/AT32).

**Итого:** 
- На этапе модернизации **оставь STM32 UART подключенным для логов**, но в коде сделай его опциональным `#define STM32_DEBUG_UART 1` — если отключишь, функционал не ломается, просто меньше логов.
- Для проверки **shuffle без пропусков, SD без WiFi, PROGRESS/SEEK, USB-Flash** достаточно **Web UI + UART ESP32-S3 + ухо**. STM32 UART — бонус для отладки mute/rate.
- В финальном OMNIA интеграции STM32 UART уходит вместе со стендом.

## Как тестировать каждый этап только с твоими средствами

### Этап Shuffle fix + Repeat
- UART ESP32-S3: `shuffle on`, `repeat all`, `list`, `info`
- Web UI: список треков, иконка shuffle
- Ухо: 10 треков shuffle repeat off → проигрались 10 уникальных без повтора, затем стоп. На старый баге пропускался 1 трек — на слух заметишь что одного нет, в логах `##TRACK# idx/total`.

### SD без WiFi
- Выключить роутер, перезагрузить ESP32-S3 + STM32 стенд.
- UART ESP32-S3: должно быть `SD Mounted`, `##SD.STATUS#: mounted`, даже при `WIFI STATUS 0`
- Web UI: должен открыться AP или сразу показать SD список (зависит от настроек yoRadio), играть без интернета.
- Ухо: играет.

### Progress + Seek
- UART ESP32-S3: `##PROGRESS#: <cur_ms> <dur_ms> <state> <percent_x10>` 2-5Hz, при hold seek до 10Hz
- Web UI: slider движется, elapsed/remaining обновляется, seek перетаскиванием.
- Ухо: seek без щелчка, короткий soft-mute 50-120ms, затем точная позиция. Hold NEXT/PREV → ускоряющаяся перемотка, отпускание → финальный точный seek.

### USB-Flash Host
- UART ESP32-S3: `##USB.STATUS#: mounted size=32GB fs=FAT32 files=124`
- Web UI: раздел USB, list
- Ухо: играет как SD, next/prev/seek/meta так же.
- Hot-plug: выдернуть во время play → стоп + лог `ejected` без краша, вставить → авто rescan.

### RATE/MUTE handshake (проверка через STM32 UART если подключен)
- UART STM32: `s1000` автостатус каждую секунду, при смене трека с другой Fs лог `RATE 44.1→48` + `MUTE HIGH→LOW`, `retune OK, overrun 0`
- Без STM32 UART: на слух — если RATE неправильный, скорость ускорена/замедлена + дропы через минуту. Если правильно — норм.

## Что в итоге в модернизме не нужен STM32 UART

- В финальном модуле Ё-радио для OMNIA: STM32 UART не нужен, т.к. его заменяет AT32 diagnostic UART.
- Для standalone Ё-радио вне OMNIA: STM32 вообще не нужен, если ESP32-S3 переключить в I2S MASTER (но для OMNIA нам нужен SLAVE, поэтому он нужен только как стенд).

Оставляем STM32 UART как опцию `#ifdef STM32_DEBUG` — удобно, но не критично.
